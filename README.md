# 基于 STM32F103C8T6 的红外遥控小车

## 概述

通过 NEC 协议红外遥控器控制四轮小车完成前进、后退、左转、右转与停止，并支持三档速度。主控为 STM32F103C8T6，红外接收头 HX1838，电机由 TB6612 双通道驱动。解码采用“EXTI 双沿中断 + TIM3 1µs 计时 + 有限状态机”实现，OLED 实时显示解码结果，便于调试。

## 功能

- 前进 / 后退 / 左转 / 右转 / 停止
- 三档速度（低 / 中 / 高）
- 按住按键连续运动：识别 NEC 重复码并保持当前动作，超过 300ms 没有新的重复码则自动停车
- OLED 实时显示数据码、当前方向、最近脉宽和保持标志

## 软件设计

### 红外解码

- 接收头输出接 PA6，配置为双边沿 EXTI；每次边沿读取 TIM3 计数值，与上次比较得到脉宽（处理计数器溢出）。
- 有限状态机共 4 个状态：
  - `IR_IDLE`：等待 9ms 引导低电平；
  - `IR_START_HIGH`：判断 4.5ms 起始高电平或 2.25ms 重复码；
  - `IR_RECEIVE_DATA`：接收 32 位数据，560µs 判逻辑 0、1690µs 判逻辑 1；
  - `IR_REAPT_LOW`：确认 560µs 重复码。
- 收满 32 位后按 NEC 格式拆出地址码、地址反码、数据码、数据反码，反码校验通过才更新命令。
- 解码在中断回调中完成，主循环只负责执行命令和刷新 OLED。

### 命令与运动控制

- 命令分为方向枚举（STOP / FORWARD / BACK / LEFT / RIGHT）与速度枚举（SPEED1 / SPEED2 / SPEED3）。
- 数据码映射：0xA2 / 0x62 / 0xE2 → 低 / 中 / 高速度；0x18 / 0x4A / 0x10 / 0x5A → 前 / 后 / 左 / 右；其余默认停止。
- 重复码保持：收到重复码置位 `is_hold`，300ms 内没有新的重复码则自动清除并停车。
- 电机层：TB6612 两路 PWM 差速转向；前进时右轮额外 +100 PWM 补偿直行偏差；原地转向时左右轮给固定占空比。

### 显示

- OLED 显示数据码（十六进制）、方向字符串、最近脉宽、保持标志，方便观察解码是否正确。

## 调试要点

- 用 TIM3 1µs 计数测脉宽，比 `HAL_Delay` 精度高，且不占用 CPU 轮询。
- 双边沿 EXTI 可以同时测高、低电平宽度，配合状态机区分引导码、数据位和重复码。
- NEC 的 9ms + 4.5ms 与重复码的 9ms + 2.25ms 容易混淆，状态机中用 `is_hold` 区分，避免重复码误入数据接收。
- 面包板供电注意共地；TB6612 的 VM 与逻辑 5V 分开走线，避免电机启动瞬间拉低逻辑电源。
